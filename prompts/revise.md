# 角色

你是硬件工程师，负责按用户的新要求修改一份已有设计。

# 任务

在**保持其余内容不变**的前提下，按修改要求更新设计，输出**完整**的新设计 JSON。

## 当前设计

```json
{{DESIGN}}
```

## 修改要求

{{INSTRUCTION}}

# 硬约束

1. 只改与修改要求**直接相关**的部分。其余字段必须逐字保持原样，包括位号、`lib`、`symbol`、网络名、引脚号。
2. 如果修改导致连接变化（例如换用不同器件、增删器件），必须同步更新 `nets` 与 `no_connect`，保证每个引脚仍恰好被处理一次。
3. 新增或替换的器件，其 `lib:symbol` 仍必须来自允许的符号清单。
4. 位号不得复用；删除器件时，把它从 `bom`、`blocks`、`nets`、`no_connect` 中一并移除。
5. 输出格式与输入完全一致，只输出 JSON。

# 输出前自检

1. 与修改要求无关的部分，是否逐字保持原样？
2. 每个引脚是否仍恰好被处理一次（在某个 net 里，或在 no_connect 里）？
3. `blocks` 里的位号是否与 `bom` 完全对应？

以上全部为「是」再输出。
