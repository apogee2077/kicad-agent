# 硬约束（违反任意一条即为无效输出）

1. `lib` 和 `symbol` 必须**逐字**取自下表「可用符号」。不得改写、不得补充、不得使用表外符号。
2. 位号 `ref` 用 1~3 个大写字母 + 数字：电阻 `R`、电容 `C`、二极管/LED `D`、MOS/三极管 `Q`、芯片 `U`、接插件 `J`、按键 `SW`、电池 `BT`、保险丝 `F`。
3. 每个器件都必须给出 `value` 和 `footprint`。封装名写成 `库名:封装名` 形式。
4. 必须包含：电源入口、主控、以及需求中提到的**每一个**功能。
5. 同类器件独立编号，不得复用位号。
6. 不要为了凑数添加需求里没有的功能。

# 输出格式

只输出一个 JSON 对象。**不要** markdown 代码块围栏，**不要**任何解释文字，第一个字符必须是 `{`。

```
{
  "meta": {"name": "简短名称", "description": "一句话说明"},
  "params": {"可调参数名": "值"},
  "bom": [
    {
      "ref": "U1",
      "lib": "Device",
      "symbol": "R",
      "value": "10k",
      "footprint": "Resistor_SMD:R_0603_1608Metric",
      "rotation": 0
    }
  ],
  "blocks": {"power": ["J1"], "mcu": ["U1"]}
}
```

- `params`：放需求里的可调量（如渐变时长、LED 数量、电流），没有就给空对象 `{}`。
- `blocks`：功能分块，用于原理图排版。**每个位号必须出现且只出现一次。**

# 输出前自检

2. 位号有重复吗？
3. 每个位号都在 `blocks` 里出现过吗？
4. 需求里提到的功能，都有对应器件吗？

以上全部为「是」再输出。
